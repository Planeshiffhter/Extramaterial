# Lily Takes the Train

A **55-second English-learning video**, made in Blender, with narration and highlighted captions. The viewing copy is **1280 × 720 at 24 fps** and includes all 12 supplied dialogue lines.

- [Watch or download the video](Lily_Takes_the_Train.mp4)
- [Download the editable Blender project and supporting files](Lily_Blender_Project.zip)
- [Read the project credits](CREDITS.txt)

Extract the ZIP and open `Lily_Blender_Project/Lily_Takes_the_Train.blend` in **Blender 4.3 or newer**. The package includes the packed scene, a separate narration WAV, SRT captions, highlighted ASS captions, the Noto Sans Bold font and its license, and a portable `render_video.py` launcher. Follow the included `README.txt` to rerender with Blender, FFmpeg, and Python 3. No external video-generation plugin is required.

Lily uses an adapted **Ellie character and pose library by Blender Studio (CC-BY)**. Her appearance differs from the reference character. The new kitchen scene, shots, props, and caption treatment follow the reference's general presentation. The supplied viewing copy uses interpolated CPU-rendered samples; fast movements can show minor smearing. The editable project retains the full 24 fps animation timeline for native rerendering.
