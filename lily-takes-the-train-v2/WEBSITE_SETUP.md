# Activate the prepared website

The complete static gallery is already uploaded as `index.html` at the repository root, together with `.nojekyll` and all video/image/download files. It has been checked at desktop and phone sizes.

The connected GitHub app can upload repository files, but enabling Pages returned **HTTP403: Resource not accessible by integration**. Pages has a separate app permission. No live GitHub Pages site was created.

As the repository owner, open:
https://github.com/Planeshiffhter/Extramaterial/settings/pages

Under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save. GitHub will show the live URL after its build completes, normally:
https://planeshiffhter.github.io/Extramaterial/

You can already view the images/video directly in the V2 GitHub folder, or download the preview ZIP, unzip it and open **Gallery.html** locally. The offline gallery needs no hosting account or plugin.
